# Efnisbók

Vöruskrá fyrir eldhús, gólf og baðherbergi frá fyrirtækjum á höfuðborgarsvæðinu: eldhúsinnréttingar, borðplötur, flísar, parket, eldhústæki, blöndunartæki, vaskar, klósett og skolhnappar.

- **Vörur:** leitaðu, síaðu eftir fyrirtæki, verði, lit, lögun og stærð, gefðu stjörnur og skrifaðu athugasemdir.
- **Líkað:** allt sem þú hefur hjartað, raðað eftir stjörnum.
- **Moodboard:** settu saman innréttingu, borðplötu, flísar, gólf, tæki og baðvörur.
- **Myndir:** myndir seljenda eru sóttar sjálfkrafa. Þú getur líka bætt við eigin mynd (úr síma/tölvu eða vefslóð).

Allt sem þú merkir vistast í vafranum. Notaðu **Sækja afrit** reglulega og **Setja inn afrit** til að færa yfir í annað tæki.

## Hvernig myndir eru sóttar

`scripts/fetch_images.py` keyrir í GitHub Actions (`.github/workflows/images.yml`) í hvert sinn sem `data.json` breytist, á mánudögum og þegar þú ýtir á *Run workflow*. Það sækir mynd af vörusíðu hverrar vöru og vistar hana í `img/`.

Verð eru sótt 24.11.2026 og geta breyst. Staðfestu alltaf hjá seljanda.
